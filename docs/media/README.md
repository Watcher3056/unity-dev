# README recordings

`unity-flow-light.gif` and `unity-flow-dark.gif` were captured from the actual
FlowAI Graph interface on 2026-10-18, using viewer files matching Graph source `59271d6`
and the Unity-dev stage profile. The interface was not rebuilt or restyled.

The popup scenario is a scripted Normal-mode demonstration. Its code and log
excerpts come from the retained Graph demo; the displayed check results are
illustrative, not evidence of a new Unity test run. Why uses the viewer's
built-in answer from the trace, not a live model response.

The camera pans and the cursor clicks real controls. Only a pointer and click
indicator are added to the browser frames. Both themes use the viewer's own
appearance settings.

The older thumbnail, pipeline diagram and `trace-*` GIFs remain as historical
assets; the main README uses the new Flow recordings.

See [asset provenance](../asset-provenance.md).

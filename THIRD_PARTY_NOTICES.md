# External dependencies

Build-time metadata validation uses separately installed PyYAML (MIT), pinned in requirements-dev.txt: https://github.com/yaml/pyyaml/blob/main/LICENSE . The plugin runtime uses Python's standard library. No third-party library or font file is copied into the package. Agent hosts and Unity integrations are separately installed products with their own terms.

The repository's own material is covered by [LICENSE](LICENSE). See [asset provenance](docs/asset-provenance.md).
